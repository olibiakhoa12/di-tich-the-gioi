# Di Tích Lịch Sử Thế Giới

Trang web giới thiệu về các di tích lịch sử nổi tiếng trên thế giới, được sắp xếp theo các châu lục.

## Nội dung

Trang web bao gồm thông tin về 9 di tích lịch sử từ 3 châu lục:

### Châu Á
- **Great Wall of China** - Trung Quốc
- **Taj Mahal** - Ấn Độ
- **Angkor Wat** - Campuchia

### Châu Âu
- **Colosseum** - Ý
- **Sagrada Familia** - Tây Ban Nha
- **Mont Saint-Michel** - Pháp

### Châu Mỹ
- **Machu Picchu** - Peru
- **Statue of Liberty** - Hoa Kỳ
- **Christ the Redeemer** - Brazil

## Cấu trúc dự án

```
di-tich-the-gioi/
├── index.html      # Trang HTML chính
├── style.css       # Stylesheet CSS
└── README.md       # Tài liệu này
```

## Tính năng

- Giao diện responsive (phản hồi trên các thiết bị khác nhau)
- Navigation menu dễ sử dụng để truy cập các châu lục
- Thiết kế card đẹp mắt cho mỗi di tích
- Chỉ sử dụng HTML và CSS (không có JavaScript)
- Hỗ trợ hiển thị trên desktop, tablet và mobile

## Cách sử dụng

1. Clone repository này
2. Mở file `index.html` trong trình duyệt web
3. Khám phá các di tích lịch sử thế giới

## Công nghệ sử dụng

- HTML5
- CSS3
- Responsive Design
